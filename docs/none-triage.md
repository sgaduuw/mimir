# Nullable-value triage (#1196)

Reviewed against develop `e0a59455` on 2026-11-15. Original locations below
are the issue's coordinates, so they remain stable as edits shift lines.
All 31 sites were traced through producers and callers. One reproduced
runtime defect accounts for three crawler-budget sites. The other 28
sites already had a guard, a producer invariant, or safe nullable lookup
semantics. Their changes make those reasons explicit in the code.

The defect is an accepted listed-user-agent name, `(impossible headers)`,
colliding with the internal header-bucket label when that bucket is disabled.
The new HTTP regression reproduces a 500 before the fix and verifies a normal
response followed by the configured 429 budget response afterward. The source
selection now requires the header bucket to exist before selecting it.

No mypy dependency or CI gate was added. Existing behavior tests verify the
invariant-only changes; the new regression exercises the confirmed defect.
